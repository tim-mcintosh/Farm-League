# Farm League game template

Copy this directory to `games/<game-slug>/`, then:

1. Replace the game name, page title, and description in `index.html`.
2. Implement game-specific presentation in `styles.css`.
3. Implement game state, input, update, and render logic in `game.js`.
4. Provide equivalent keyboard and touch controls.
5. Keep the **Back to Farm League** link and verify all relative paths.
6. Add the game to the homepage only when it is ready to play.

Do not put platform services or another game's code in this directory. Reusable site assets belong in `assets/shared/`.
